O que é JavaScript?

O JavaScript foi criado para tornar as páginas da internet mais interativas, permitindo ações como responder a cliques, validar formulários, alterar conteúdos e criar animações. No navegador, o JavaScript é executado pelo próprio navegador do usuário, como Google Chrome, Microsoft Edge ou Firefox. Já no servidor, ele pode ser executado com tecnologias como o Node.js, sendo usado para criar sistemas, acessar bancos de dados e processar informações. No navegador, o JavaScript funciona em uma sandbox, ou seja, em um ambiente limitado e protegido, sem acesso livre aos arquivos do computador do usuário. Alguns objetos globais importantes são document, usado para acessar e modificar elementos da página; console, usado para mostrar mensagens no console do navegador; e alert, usado para exibir caixas de aviso na tela.
